Every model is fingerprinted once a day, per host. One square is one day, and the window runs forward 90 days from 21 August 2026. A square lights up only on the day a value changed. Dashed squares are days with no measurement, either because the day has not arrived or the model was not tracked yet. When a window fills, the next one is added beside it and you can scroll back. This page records what changed, never why.
